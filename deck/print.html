Before you print

  1. Match the paper size above. Choose portrait, 100% / actual size, one page per sheet. Turn off headers and footers; use no extra margins.
  2. Enable two-sided printing and flip on the long edge. Sheets alternate front, back, front, back.
  3. Print the first sheet on plain paper. Hold it to the light to check alignment. The calibration line should measure 50 mm.
  4. Cut on the corner guides. Each card is 60 × 90 mm, with at least a 2 mm white border that keeps every part of the art visible.

Printer alignment varies. Keep the same settings for both sides; check paper handling before using card stock. Background graphics are not required.

Printing both sides by hand?

Print fronts only, then reinsert the stack and print backs only. Match sheet numbers: front 1 with back 1, through front 6 with back 6. Select reverse back order only if your printer feeds the last front sheet first. Use the first-sheet test to learn your printer’s face-up / face-down feed and edge orientation.
